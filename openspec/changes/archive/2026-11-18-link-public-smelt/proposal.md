# Proposal

## Why

Smelt, the tool that built every task of this project, is becoming a public repository (all rights reserved, like courier). courier's README and `docs/development.md` still call it "private" and give no link, so readers cannot check how the project was built.

## What Changes

- In `README.md` ("How it is built") and `docs/development.md` ("Smelt"), describe Smelt as the author's own software factory, public for review at https://github.com/fabianskier/smelt under an "all rights reserved" notice (not open source), still not needed to build, run or test courier.
- Documentation only.

## Capabilities

### New Capabilities
None.

### Modified Capabilities
None.

## Impact

`README.md`, `docs/development.md`.
